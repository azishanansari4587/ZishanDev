# 🧑‍💻 Zishan's Developer Portfolio

A personal portfolio website to showcase my skills, projects, and experience as a Full Stack Developer. Built with modern web technologies including **Next.js** and **Tailwind CSS**, this site highlights my freelance work and technical capabilities.

## 🚀 Live Website

👉 [zishan-dev.vercel.app](https://zishan-dev.vercel.app/)

## 📌 Features

- ⚡ Responsive and mobile-friendly design  
- 🧠 Showcases skills, projects, and contact information  
- 💼 Freelance project highlights  
- 🌐 SEO-optimized and fast performance  
- ☁️ Deployed on Vercel

## 🛠️ Tech Stack

- **Frontend**: Next.js, React.js, Tailwind CSS, HTML5, CSS3, JavaScript ES6+
- **Backend (for APIs)**: Node.js, Express.js (optional for expansion)
- **Database**: MySQL / MongoDB (based on projects)
- **Version Control**: Git, GitHub
- **Deployment**: Vercel

## 📂 Folder Structure

├── /public         # Static assets like images, icons, fonts, etc.
├── /components     # Reusable UI components like Navbar, Footer, Cards, etc.
├── /pages          # Next.js pages (e.g., Home, About, Projects, Contact)
├── /styles         # Global styles and Tailwind/custom CSS files
├── /data           # (Optional) JSON or JS files for dynamic data like skills, projects, etc.




## 🧾 Sections Included

- 🏠 Home – Introduction and hero section  
- 👨‍💻 About – Personal background and career goals  
- 🛠️ Skills – Technologies and tools used  
- 📁 Projects – List of freelance and personal projects  
- 📬 Contact – Contact form or social links  

Visit [Zishan Dev Portfolio](https://zishan-dev.vercel.app/) to see it live.
